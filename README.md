Craftia is a built from the ground up "add it all" game, coded in rust with it's own custom engine, also done in rust.

(To be clear, this is mostly done with ai. I started this project as a test to see how far one could push ai with enough proper guidance on a larger scale. This is not a showcase of my skills as a coder nor should be used as such, ever. I do not consider it an actually good game and I doubt it ever will be, ai is not yet good enough to do most of this on it's own.)

cargo run --release To Compile and Launch
